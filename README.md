# BARLOG

**Your pocket cocktail handbook.**

BARLOG is a mobile-first cocktail reference application designed for bartenders and cocktail enthusiasts. It brings classic and contemporary cocktail recipes together in one convenient place.

## Features

- **Cocktail Library** — browse a collection of 100 IBA cocktails.
- **IBA Categories** — explore The Unforgettables, Contemporary Classics, and New Era Drinks.
- **Recipe Details** — view ingredients, measurements, glassware, ice, garnish, and preparation methods.
- **Search & Filtering** — find cocktails in the library.
- **My Lab** — a dedicated space for personal cocktail experiments.
- **Saved Cocktails** — keep track of selected recipes.
- **Multilingual Interface** — Ukrainian and Russian languages.
- **Chef AI Assistant** — a demo assistant interface for cocktail-related interactions.

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Getting Started

Clone the repository:

```bash
git clone https://github.com/alexander-tupkalo/barlog.git
```

Navigate to the project directory:

```bash
cd barlog
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Build

To create a production build:

```bash
npm run build
```

## Project Status

BARLOG is an ongoing personal project. The current version focuses on the frontend experience and cocktail reference functionality. Backend integration, real user authentication, and persistent cloud storage are planned for future development.
